## Recent GitHub news

Source: [GitHub Changelog](https://github.blog/changelog/). Dates are 2026.

- **Stacked pull requests are generally available (Oct 6).** Split a big change into small, separately reviewable PRs that merge together. Rebasing a stack now keeps approvals on unchanged code. [Read more](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available)
- **Bulk-convert branch protections to rulesets (Oct 20).** In *Settings → Rulesets*, use *Import branch protection rules* to preview and convert every rule in a repository at once. [Read more](https://github.blog/changelog/2026-10-20-bulk-migrate-branch-protections-to-rulesets-for-a-repository)
- **Local sandboxing for Copilot is generally available (Oct 7).** Commands run by Copilot in the CLI, the Copilot app, and VS Code Agent Host sessions can be limited in file, network, and credential access. [Read more](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)
- **Actions workflow lockfiles are in public preview (Oct 14).** Pin the exact commits a workflow's actions run with the `gh actions-lock` extension, even if a tag or branch moves. Preview only, so not yet generally available. [Read more](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview)
